# Identity Security Baseline

## Objective

Build a basic identity-security baseline before introducing advanced access controls.

## Topics

- Users and groups
- Administrative roles
- Least privilege
- Role separation
- Cloud-only vs synchronized identities
- Administrative account separation

## Lab Checklist

- Review tenant users
- Identify privileged roles
- Separate standard and administrative identities
- Review group-based access
- Document high-impact roles
- Identify accounts that should never be used for daily work

## Security Questions

- Which identities can change security controls?
- Which identities can assign privileged roles?
- Which accounts have standing privilege?
- Are service accounts or workload identities overprivileged?
- Are administrator identities used for normal productivity work?

## Expected Outcome

A documented view of the tenant's identity-security baseline and the identities requiring stronger controls.
