# Access Reviews Lab

## Objective

Validate that users retain access only when it is still required.

## Use Cases

- Privileged group membership
- Guest access
- Application access
- Sensitive groups
- Project-based access

## Lab Workflow

1. Select a target group or application.
2. Define reviewers.
3. Configure review frequency.
4. Define what happens when no decision is made.
5. Run the review.
6. Record decisions.
7. Validate removal of unnecessary access.

## Security Questions

- Who still needs access?
- Who has not used the resource?
- Are guests still required?
- Are privileged memberships justified?
- Is access automatically removed after denial?

## Outcome

Document how periodic access validation reduces privilege accumulation over time.
