# Entitlement Management Overview

## Objective

Understand lifecycle-based access provisioning.

## Concepts

- Access packages
- Catalogs
- Resources
- Request policies
- Approval
- Expiration
- Reviews

## Example Lab Scenario

Create an access package for a fictional project:

```text
Project-Security-Lab
├── Security-Lab-Users group
├── Test application
└── SharePoint test resource
```

Define:
- Who may request access
- Whether approval is required
- How long access lasts
- Whether access is reviewed
- What happens when access expires

## Security Benefit

Entitlement Management helps reduce manual provisioning and long-lived access that is no longer required.
